# Interview Questions

## 1. What is explainable AI and why is it important?

Explainable AI refers to the ability of a machine learning model to provide insights into its decision-making process. It is important because it helps to build trust in the model and ensures that the model is fair and transparent.

## 2. How does the SHAP value method work?

The SHAP value method is a technique used to explain the output of a machine learning model. It works by assigning a value to each feature for a specific prediction, indicating its contribution to the outcome.

## 3. What is LIME and how does it work?

LIME is a technique used to explain the output of a machine learning model. It works by generating an interpretable model locally around a specific prediction and then using this model to explain the prediction.
