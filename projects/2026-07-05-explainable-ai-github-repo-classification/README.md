# Explainable AI for Open-Source GitHub Repository Classification

This project develops an explainable machine learning model to classify GitHub repositories into categories like web development, machine learning, or data science, and provide insights into the decision-making process.

## Getting Started

1. Clone the repository: `git clone https://github.com/your-username/explainable-ai-github-repo-classification.git`
2. Navigate to the project directory: `cd explainable-ai-github-repo-classification`
3. Run the demo: `python src/main.py`

## Tests

1. Navigate to the tests directory: `cd tests`
2. Run the tests: `python test_main.py`
