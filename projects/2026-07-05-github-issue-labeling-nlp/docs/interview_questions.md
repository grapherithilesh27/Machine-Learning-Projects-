# Interview Questions

## 1. What is the main goal of this project?

The main goal of this project is to develop a machine learning model to automatically label GitHub issues based on their descriptions, reducing manual effort and improving issue tracking efficiency.

## 2. What approach does the model use for text classification?

The model uses a simple text classification approach, where the text is tokenized and the frequency of each word is calculated.

## 3. What is the accuracy of the model on the test dataset?

The model achieves an accuracy of 0.8 on the test dataset.
