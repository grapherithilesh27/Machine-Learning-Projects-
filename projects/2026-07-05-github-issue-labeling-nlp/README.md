# Automated GitHub Issue Labeling using Natural Language Processing

This project develops a machine learning model to automatically label GitHub issues based on their descriptions, reducing manual effort and improving issue tracking efficiency.

## Requirements

* Python 3.x

## Usage

1. Clone the repository: `git clone https://github.com/username/github-issue-labeling-nlp.git`
2. Navigate to the project directory: `cd github-issue-labeling-nlp`
3. Run the demo: `python src/main.py`
